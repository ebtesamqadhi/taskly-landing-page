# Taskly

Taskly is a modern and responsive task management landing page built with React. This project was created to practise reusable components, React Hooks, and responsive web design.

## Live Demo

[View Taskly Website](https://ebtesamqadhi.github.io/taskly-landing-page/)

## Features

- Fully responsive design
- Reusable React components
- Animated statistics
- Interactive FAQ section
- Pricing and testimonials sections
- Smooth navigation between sections

## Technologies

- React
- JavaScript
- Vite
- Bootstrap
- CSS
- Lucide React

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ebtesamqadhi/taskly-landing-page.git
```

Open the project directory:

```bash
cd taskly-landing-page
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Deployment

The project is deployed using GitHub Pages and GitHub Actions.
